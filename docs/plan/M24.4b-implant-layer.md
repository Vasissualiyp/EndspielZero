## What this is, in one paragraph

The player has a neural implant. The menus are written into the visual cortex and
**perceived** over the room. They are not a screen in front of the eyes. So they look
**organic**, never digital:
- colour drifts apart in slow curling flows and converges onto the panel;
- glyphs resolve from soft blobs;
- a panel leaves by breaking into soft points of light, with a faint afterimage;
- the whole layer carries a barely visible heartbeat;
- the layer dims while the camera swings fast, as perception does during a saccade.

The board's LEDs are the opposite: square pixels, scan lines and hard steps. **Never use
an LED motion in the implant layer, and never an implant motion on the hardware.**

## Scope of this slice

- **On the lab path only** (lab on, a menu screen, not the Editor): the synaptic hue, and
  the implant composite with form, dissolve, afterimage, heartbeat and saccadic dip.
- The first-launch handshake (phosphenes, the log-polar ring wave) is **not** here; it is
  M24.7. This slice leaves a `globalSync` input fixed at 1 for it.
- The game screen and pause are not on the lab path until M24.5, so they are unchanged.
- The debug console, the dev overlay (fps) and the Editor are **never** composited: they
  are tools, not perception. They are drawn after the composite, unchanged.

## Step 2 — pure timing for the implant (test first)

New files `src/view/implant_fx.{hpp,cpp}`:

```cpp
namespace cb::view {

inline constexpr float kImplantFormSeconds = 0.35f;
inline constexpr float kImplantDissolveSeconds = 0.25f;
inline constexpr float kImplantAfterimageSeconds = 0.30f;  ///< after the dissolve
inline constexpr float kImplantAfterimageLevel = 0.08f;
inline constexpr float kHeartbeatAmplitude = 0.02f;
inline constexpr float kHeartbeatBpm = 60.0f;
inline constexpr float kHeartbeatSecond = 0.25f;  ///< "dub" after "lub", seconds
inline constexpr float kSaccadeMaxDip = 0.60f;
inline constexpr float kSaccadeFullSpeed = 3.0f;  ///< rad/s at which the dip is maximal

/// Brightness multiplier of the heartbeat at `seconds` (visual time): 1 + A*pulse.
/// pulse = g(phi) + 0.6*g(phi - kHeartbeatSecond*bpm/60), g(x) = exp(-x*x / 0.0016),
/// phi = fract(seconds * bpm / 60) wrapped to [-0.5, 0.5). Calm: exactly 1.
[[nodiscard]] float heartbeat(double seconds, float intensity) noexcept;

/// The saccadic dip, 0..kSaccadeMaxDip, from the camera's angular speed. Calm: 0.
[[nodiscard]] float saccadicDip(float radPerSecond, float intensity) noexcept;

/// One panel's implant state at `age`. Forming: progress 0..1 over kImplantFormSeconds.
/// Leaving: dissolve 0..1 over kImplantDissolveSeconds, then afterimage 1..0 over
/// kImplantAfterimageSeconds. `visible()` is false once the afterimage is over.
struct ImplantPanelState {
  float form{1};        ///< 1 = fully formed
  float dissolve{0};    ///< 1 = fully dissolved
  float afterimage{0};  ///< 0..kImplantAfterimageLevel
  [[nodiscard]] bool visible() const noexcept;
};
[[nodiscard]] ImplantPanelState implantForming(float age, float intensity) noexcept;
[[nodiscard]] ImplantPanelState implantLeaving(float age, float intensity) noexcept;

}  // namespace cb::view
```

- **Calm** (intensity < 0.5): `implantForming` goes from `form = smooth(age / 0.2)`, a
  plain fade that the composite treats as alpha only (see Step 4). `implantLeaving` has
  `dissolve = smooth(age / 0.2)` and no afterimage.
- **`saccadicDip`:** `kSaccadeMaxDip · smooth(clamp(ω / kSaccadeFullSpeed, 0, 1))`.

**Tests** (`tests/unit/view/test_implant_fx.cpp`, `[unit][view][implant]`):
- **heartbeat:**
  - it is exactly 1 at calm;
  - it lies in [1, 1.02 + 1e-6];
  - it peaks within ±0.02 s of each whole second;
  - its second peak, 0.25 s later, is smaller;
- **saccadicDip:** 0 at 0 rad/s, 0.6 at ≥ 3 rad/s, and 0 at calm;
- **implantForming:** age 0 gives form 0 and age ≥ 0.35 gives form 1;
- **implantLeaving:**
  - dissolve is 1 at 0.25;
  - the afterimage is at its maximum (0.08) just after 0.25 and is 0 at ≥ 0.55;
  - `visible()` is false after 0.55.

## Step 4 — the composite pass (Vulkan)

### Overview

Today the UI is recorded by the `overlay` callback **directly onto the frame** in the last
pass of `BoardRenderer::record` (`board_renderer.cpp`, around lines 2748–2766: begin
rendering on `target.colorView()` with `LOAD_OP_LOAD`, call `overlay(cmd)`, end). On the
implant path, instead:
1. Record the composited part of the UI into a separate **UI layer image**, cleared to
   transparent.
2. Composite that image over the frame with `implant.frag`.
3. Record the uncomposited UI (console, dev overlay) directly on the frame, as today.

When the implant path is off, the code must run exactly the old path. No new pass, no
new image use.

### 4.1 One ImGui draw, with "tool rects" left untouched

Record the whole ImGui frame into the layer with the existing **single**
`ImGui_ImplVulkan_RenderDrawData` call (`Ui::record`). **Do not call
`RenderDrawData` twice in one frame**: the backend reuses per-frame vertex buffers, and a
second call would overwrite the first before the GPU reads it.

The debug console and the dev overlay (fps) must not get implant effects. So the `Ui`
reports their window rectangles as **tool rects**, and the composite shader passes layer
pixels inside a tool rect through untouched: no displacement, blur, sparks, heartbeat or
dip.
- Get each rect with `ImGui::GetWindowPos()` / `GetWindowSize()` inside the window's
  `Begin`/`End` (grep `Begin(` in `Ui::drawDebugConsole` and in the fps overlay code).
  Store it in `std::vector<std::array<float,4>> toolRects_`, cleared each frame.
- Expose it as `std::span<const std::array<float,4>> Ui::toolRects() const`.

### 4.2 The layer image

Create `src/render/implant_layer.{hpp,cpp}`:

```cpp
namespace cb::render {

/// The implant layer (M24.4b): a per-frame-slot RGBA image the interface is drawn into,
/// and the pass that composites it over the frame with the implant's organic effects.
class ImplantLayer {
 public:
  static Result<ImplantLayer> create(const VulkanContext& ctx, VkFormat targetFormat);
  /// (Re)create the slot's image at this size if it changed.
  Result<void> prepare(std::uint32_t width, std::uint32_t height, std::uint32_t slot);
  /// Begin rendering into the layer (clear to 0,0,0,0). Leaves it as a colour attachment.
  void beginLayer(VkCommandBuffer cmd, std::uint32_t slot);
  void endLayer(VkCommandBuffer cmd, std::uint32_t slot);   // -> SHADER_READ_ONLY
  /// Draw the layer over `target` with the effects in `params`.
  void composite(VkCommandBuffer cmd, const OffscreenTarget& target,
                 const ImplantParams& params, std::uint32_t slot);
  // move-only, destructor frees everything
};

struct ImplantParams {
  float time{0};          ///< visual seconds
  float intensity{1};
  float globalSync{1};    ///< M24.7 handshake; 1 in this slice
  float heartbeat{1};     ///< multiplier from view::heartbeat
  float dip{0};           ///< from view::saccadicDip
  float pixelScale{1};    ///< framebuffer height / 1080
  struct Panel { float rect[4]; float form, dissolve, afterimage, seed; };
  std::array<Panel, 16> panels{};
  std::uint32_t panelCount{0};
  std::array<std::array<float, 4>, 4> toolRects{};
  std::uint32_t toolCount{0};
  float warm[4]{};        ///< theme implantWarm, linear
};

}  // namespace cb::render
```

Image details:
- **Format:** `targetFormat` (the same as the frame), so the ImGui pipeline, which was
  created for that colour format (`ui.cpp` around line 546:
  `rendering.pColorAttachmentFormats = &targetFormat`), can draw into it unchanged.
- **Usage:** `COLOR_ATTACHMENT | SAMPLED`.
- **The attachment structure** of `beginLayer` must be **exactly** like the existing
  overlay pass: one colour attachment and no depth attachment. The existing pass works
  with the ImGui pipeline; mirror it.
  - The only difference is `loadOp = VK_ATTACHMENT_LOAD_OP_CLEAR`, with clear colour
    {0, 0, 0, 0}.
- **Blend.** The ImGui backend blends colour with `SRC_ALPHA / ONE_MINUS_SRC_ALPHA` and
  alpha with `ONE / ONE_MINUS_SRC_ALPHA`. Drawing onto a transparent clear therefore
  produces **premultiplied** colour and a correct coverage alpha. The composite assumes
  premultiplied input.
- **sRGB.** If the target format is an `_SRGB` format, both images are sRGB. Sampling
  returns linear values and writing re-encodes, so the result is consistent. Note in
  Status which format the target actually uses (grep `OffscreenTarget::create` and the
  swapchain format).
- **Sampler:** linear filtering, `CLAMP_TO_EDGE`.
- **Descriptor:** one combined image sampler per slot.
- **Uniforms:** a per-slot uniform buffer holding `ImplantParams` in std140. Lay it out
  as vec4s only, to avoid std140 traps: pack `Panel` as two vec4s
  (rect; form, dissolve, afterimage, seed), and the scalars as vec4s.
  `static_assert` the size.
- **Pipeline:** the full-screen triangle `blur.vert` (it already generates `fragUv` from
  `gl_VertexIndex`; reuse the compiled module) plus the new `implant.frag`.
  - Colour blend `ONE / ONE_MINUS_SRC_ALPHA` for colour, `ONE / ONE_MINUS_SRC_ALPHA` for
    alpha, because the output is premultiplied.
  - Dynamic rendering with the target's colour format, and no depth.
- **Register the shader** in `src/render/CMakeLists.txt`'s shader list, next to
  `post_composite.frag` (around line 22).

## Step 5 — the shader `src/render/shaders/implant.frag`

Inputs:
- `fragUv` (0..1);
- `layout(set=0, binding=0) uniform sampler2D ui;`;
- `layout(set=0, binding=1) uniform Params { ... }` matching `ImplantParams`.

Output: `vec4 outColor`, premultiplied.

Write these helpers at the top:
- `float hash12(vec2)`;
- `float noise(vec2)` (value noise with smooth interpolation);
- `float fbm(vec2)` (4 octaves);
- `vec2 curl(vec2 p, float t)`:
  - let `e = 0.01` and `n(q) = noise(q + vec2(0.0, t))`;
  - return `vec2(n(p + vec2(0, e)) − n(p − vec2(0, e)), −(n(p + vec2(e, 0)) − n(p − vec2(e, 0)))) / (2e)`;
  - then normalise to length ≤ 1 by dividing by `max(1, length)`.

Per pixel, in this order:
```
px      = fragUv * screenSize            // screenSize from Params (add it: width, height)
// 1. tools are untouched
if (px inside any toolRect) { outColor = texture(ui, fragUv); return; }

// 2. which panel influences this pixel: the record whose rect, grown by 24*pixelScale px,
//    contains px and whose state is most "unsettled" (min form, or max dissolve/afterimage).
//    No record -> settled: local = 1, no effects except heartbeat and dip.

// 3. per-pixel organic progress
n       = fbm(px / (180*pixelScale) + seed)                         // 0..1
// forming: each pixel resolves at its own moment
localF  = smoothstep(n*0.6, n*0.6 + 0.4, form)                       // 1 = resolved
// leaving: each pixel breaks up at its own moment
localD  = 1 - smoothstep(n*0.6, n*0.6 + 0.4, dissolve)               // 1 = still there
local   = min(localF, localD)
unsync  = 1 - local                                                  // 0 settled .. 1 raw

// 4. flowing colour separation (only where unsynced)
flow    = curl(px / (screenSize.y / 6.0), time * 0.3)               // ~1/6-screen eddies
amp     = unsync * 6.0 * pixelScale                                  // px
offR    =  flow * amp / screenSize
offB    = -flow * amp / screenSize
offG    =  flow.yx * amp * 0.3 / screenSize
// 5. soft focus (only where unsynced): 8-tap Poisson disc, radius unsync*4*pixelScale px
r = blurSample(fragUv + offR, radius).r
g = blurSample(fragUv + offG, radius).g
b = blurSample(fragUv + offB, radius).b
a = blurSample(fragUv,        radius).a
// warm fringe: where R and B disagree, tint the excess toward implantWarm
fr = max(r - b, 0.0) * unsync
col = vec3(r, g, b) + warm.rgb * fr * 0.5
// 6. the panel dissolves into its pixels' own progress
col *= local; a *= local
// 7. phosphenes while forming or dissolving: soft sparks on an 18px grid
cell = floor(px / (18*pixelScale)); h = hash12(cell + seed)
if (h > 0.965 && unsync > 0.05) {
   c  = (cell + 0.5 + 0.3*(vec2(hash12(cell+1.7), hash12(cell+3.1)) - 0.5)) * 18*pixelScale
   d  = length(px - c) / (5*pixelScale)
   s  = exp(-d*d) * unsync * (0.6 + 0.4*sin(time*7.0 + h*50.0))
   col += implantBody * s * 0.8; a = max(a, s * 0.8)               // implantBody = Params
}
// 8. afterimage: a faint negative of the leaving panel, slightly blurred
if (afterimage > 0) {
   g0 = blurSample(fragUv, 3*pixelScale)                            // the ghost is still drawn
   lum = dot(g0.rgb, vec3(0.299, 0.587, 0.114))
   neg = (vec3(1.0) - implantBody) * lum * afterimage / max(afterimageMax, 1e-4) * 0.08
   col = neg; a = lum * 0.08 * afterimage / afterimageMax
}
// 9. global: heartbeat and saccadic dip, on everything composited
col *= heartbeat * (1 - dip); a *= (1 - dip)
// 10. calm: no displacement, blur, sparks or afterimage -- just alpha
//     (handled by passing intensity: if intensity < 0.5, skip steps 4,5,7,8 and use
//      local = form or 1-dissolve directly)
outColor = vec4(col, a)
```
- `blurSample(uv, radiusPx)` uses a fixed 8-tap Poisson disc plus the centre. With
  `radiusPx < 0.5` it returns `texture(ui, uv)` exactly. That keeps settled pixels exact.
- `implantBody` and `afterimageMax` come from Params. Add `float body[4]` (theme
  `implant`, linear) and use `kImplantAfterimageLevel` for `afterimageMax`.
- **Settled exactness:** with no records, `heartbeat = 1` and `dip = 0`, every step is
  skipped or multiplies by exactly 1, so `outColor = texture(ui, fragUv)`. Composited
  with `ONE / ONE_MINUS_SRC_ALPHA`, that is the same maths as ImGui drawing directly,
  except for the 8-bit quantisation of the intermediate layer, which accumulates where
  UI draws overlap. So the frame equals the old path within **±2/255 per channel**, not
  bit for bit. Test exactly that. (Amended: a first implementation measured 2 on
  overlapping draws; 2 code values are invisible.)

## Step 6 — wire it up in `main.cpp`

Each frame, on the lab path with `implantFx` on:
```cpp
render::ImplantParams p;
p.time = visualSeconds;  p.intensity = presentationIntensity;
p.heartbeat = view::heartbeat(visualSeconds, p.intensity) ;   // see --heartbeat below
p.dip = (*ui)->saccadicDip();
p.pixelScale = height / 1080.0f;
for (const auto& r : (*ui)->implantRecords()) {               // at most 16; drop extras
  const auto st = r.leaving ? view::implantLeaving(r.age, p.intensity)
                            : view::implantForming(r.age, p.intensity);
  if (!st.visible() && r.leaving) continue;
  p.panels[p.panelCount++] = {{r.rect...}, st.form, st.dissolve, st.afterimage, float(r.seed % 997)};
}
/* tool rects: the console window and the fps overlay if shown (Ui exposes them) */
renderer->setImplant(p);
```
Off the implant path: `renderer->setImplant(std::nullopt)`.

- **Setting:** `bool implantFx{true};` (file key `implant_fx`, console alias `implantFx`).
  When false on the lab path, keep the synaptic hue but use nullopt, so the old pane
  fades from M24.4a apply.
- **CLI:**
  - `--implant 0|1` (run-only);
  - `--panel-t <s>` pins every panel record's age, for captures;
  - `--heartbeat 0|1` (captures default **0**, so captures stay stable; interactive
    default 1). Follow the `--ui-auto` capture-default pattern.
- **Console:** `implant [on|off]`, and `heartbeat [on|off]`.
